💍 Wedding Planner Pro
A comprehensive, vanilla JavaScript web application for planning your perfect wedding. This tool helps couples manage their budget, estimate costs, get theme suggestions, and arrange seating—all in one intuitive interface.

🚀 Features
✅ Implemented Core Features
💰 Budget Planning - Allocate funds across venue, catering, decoration, and more

📊 Cost Estimation - Real-time pricing data via external APIs

🎨 Theme Suggestions - Curated wedding themes based on your preferences

💺 Dynamic Seating Planner - Interactive drag-and-drop seating chart

🔄 Real-Time Updates - Instant budget recalculations and plan adjustments

🎯 Project Requirements Met
✅ Vanilla JavaScript (ES6+) - No frameworks used

✅ Public API Integration - Cost estimation data

✅ Dynamic DOM Manipulation - Real-time updates & interactive elements

✅ Form Validation & User Input Processing

✅ Responsive CSS Design

✅ Asynchronous Programming with Promises

🛠️ Technical Stack
Languages & Technologies
HTML5 - Semantic markup and accessibility

CSS3 - Custom styling with Flexbox/Grid

Vanilla JavaScript (ES6+) - Core application logic

Web APIs - Drag & Drop, Local Storage, Fetch API

Key JavaScript Features Used
Arrow Functions & Template Literals

Async/Await & Promises

DOM Manipulation & Event Delegation

Module Pattern & ES6 Classes

Local Storage for data persistence
